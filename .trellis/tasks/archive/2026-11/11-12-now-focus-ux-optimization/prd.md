# Now 与专注视图交互及按键优化 (PRD)

## Goal

重构 Now 视图（下一步行动流）与 Focus 视图（专注计时器）的操作流转、信息密度与按键层级，消除卡片操作拥挤与误触，提供直观的「直达专注」与「顺畅流转控制」体验。

## Background & Problems

1. **Now 列表卡片按钮过载且职责混乱 (`apps/mobile/app/(tabs)/now.tsx`)**:
   - `ActionRow` 底部平铺了「完成」「稍后」「编辑」「删除」4 个按钮，垂直方向严重占位；
   - 点击整卡只能打开编辑弹窗，左滑也是完成，但列表中**没有任何直接开始专注**的入口（只有置顶 Hero Card 才能开始专注）；
   - 4 个小按钮横排过于紧凑，在触屏或小视口下极易误触（例如误点删除或完成）。
2. **Focus 专注页启动与流转按键层级不直观 (`apps/mobile/app/focus/[id].tsx`)**:
   - 准备阶段 (Idle) 平铺了所有时长预设，未能利用行动已有的 `estMinutes` 给出优先一键开始；
   - 计时中 (Running) 将「结束专注」作为主高亮按钮、而将高频的「暂停」放在次级按钮，用户暂停喝水时极易误触提前结束；
   - 结算阶段 (Completed) 选项散乱，缺乏对「标记任务完成」核心闭环的明确引导。

## Key Decisions

- **D1 (Now 列表操作模型)**:
  - **整卡点击 (Tap)**: 直达该行动的专注页面 (`/focus/[id]?kind=...`)，契合 Now「聚焦执行」心智；
  - **快速完成**: 卡片右侧提供轻量打勾圆圈按钮，同时保留左滑「✓ 完成」手势；
  - **次要操作收敛**: 移除卡片底部平铺的 4 个占位按钮，将「编辑备注」「稍后推迟」「删除」收敛至卡片右上角「…」轻量操作菜单（或 ActionSheet）；
  - **视觉瘦身**: 削减卡片底部占位空间，提升列表信息浏览效率与呼吸感。
- **D2 (Focus 专注页三段式流转与控制重构)**:
  - **准备阶段 (Idle)**: 优先读取行动自身预计耗时 `estMinutes`（若无则取上次时长或默认 25m），提供大主按钮**「开始专注 (X 分钟)」一键直启**；下方平铺 15 / 25 / 45 / 自由计时胶囊供快速切换；
  - **计时阶段 (Running/Paused)**: **主控制键为居中醒目的「暂停 / 继续」**（主视觉焦点）；次级按钮为「结束专注」；最下方弱化放置「放弃」（避免误触丢弃记录）；
  - **结算阶段 (Completed/Time-up)**: 高亮突出主操作**「标记任务已完成」**，次按钮为「先不完成（仅记时长）」，辅以「休息 5/10 分钟」。

## Requirements

### R1. Now 列表卡片重构 (`ActionRow`)
- 整卡 `onPress` 导航到 `/focus/${action.id}?kind=${action.kind}`；
- 卡片右侧放置独立的打勾完成按钮（触控范围 ≥ 44pt），点击触发 `onComplete(action.kind, action.id)`；
- 移除卡片底部平铺的 4 个按钮行（完成、稍后、编辑、删除）；
- 卡片右上侧增加「…」更多操作按钮，点击呼出轻量上下文菜单（包含：编辑备注、稍后推迟、删除行动）。

### R2. Now 列表次要操作上下文菜单
- 实现轻量、无障碍友好的更多操作菜单（可在卡片局部弹出 Modal 或 ActionSheet）；
- 点击「编辑备注」打开现有的 `EditActionModal`；
- 点击「稍后推迟」打开现有的 `SnoozeSheet`；
- 点击「删除」触发二次确认或直接调用 `useTrashAction`。

### R3. Focus 页面 Idle 状态智能直启
- 读取当前行动的 `estMinutes`（若有效则优先作为默认分钟数，否则取 `lastMinutes` 或默认 25m）；
- 顶部/主控区展示大尺寸主按钮「开始专注 (X 分钟)」，单次点击立即进入 `running` 状态；
- 下方提供 15、25、45、自由计时等快捷胶囊，点击即切换默认分钟数。

### R4. Focus 页面 Running / Paused 控制键层级
- 计时中主视觉操作为「暂停」（运行态）或「继续」（暂停态）；
- 次级按钮为「结束专注」（记录时长并进入结算流程）；
- 辅助弱化按钮为「放弃」（带提示，防止误触丢弃计时）。

### R5. Focus 页面 Completed / Time-up 结算闭环
- 醒目高亮「完成行动」主 CTA；
- 次按钮提供「先不完成」返回 Now 列表；
- 辅助提供休息胶囊（5 分钟 / 10 分钟）。

### R6. 测试与规范保证
- 更新 `apps/mobile/__tests__/now-screen.test.tsx` 匹配新卡片交互契约；
- 更新 `apps/mobile/__tests__/focus-screen.test.tsx` 匹配新按键流转与属性；
- 满足 44pt 最小点击区域无障碍标准及 NativeWind 样式规范。

## Acceptance Criteria

- [ ] **AC-1 (Now 卡片点击)**: 点击 Now 列表中任意可执行行动卡片，路由跳转至 `/focus/[id]`。
- [ ] **AC-2 (Now 快速完成)**: 点击卡片右侧打勾按钮（或左滑），成功调用完成接口，该项从可执行列表移除。
- [ ] **AC-3 (Now 更多菜单)**: 点击卡片「…」按钮弹出菜单，支持分别触发「编辑备注」「稍后推迟」「删除行动」，功能正常运作。
- [ ] **AC-4 (Now 界面简化)**: 卡片底部平铺按钮行完全移除，卡片结构紧凑清晰。
- [ ] **AC-5 (Focus 一键开始)**: 进入 Focus 页面，默认以行动预计耗时（或预设）呈现大按钮「开始专注 (X 分钟)」，点击直接开始倒计时；切换胶囊可动态改变时长。
- [ ] **AC-6 (Focus 计时主控)**: 运行中主按钮为「暂停」，暂停中为「继续」；「结束专注」为次级按钮，「放弃」弱化放置在底部。
- [ ] **AC-7 (Focus 闭环结算)**: 专注结束后，首要高亮大按钮为「完成行动」，次级为「先不完成」。
- [ ] **AC-8 (门禁与实测)**: `pnpm verify:web` 全绿（lint / typecheck / tests / web build）；在浏览器中实测 Now 与 Focus 流转，并在 `.verify/now-focus-ux/` 保存界面截图。
