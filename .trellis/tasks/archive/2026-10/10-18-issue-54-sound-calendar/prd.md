# 专注与提醒提示音、系统日历同步（#54）

## Goal

专注结束与提醒触发时播放提示音（前台 in-app 音效 + OS 通知声音），并支持把有明确起止时间的行动同步到系统日历并设置日历提醒。

## Requirements

Issue #54：

1. **音效提示**
   - 专注计时结束时播放清晰的提示音。
   - 任务提醒（日程提醒、习惯提醒等）触发时同样播放提示音。
   - 设置中支持开关音效、选择不同音色（点击即试听），音量跟随系统音量，默认轻柔不刺耳。
2. **结合系统日历提醒**
   - 支持将任务 / 日程提醒写入手机或电脑的**系统日历**，由系统原生能力响铃 / 弹窗。
   - 设置中允许选择提醒方式：应用内提醒、系统日历提醒，或两者同时。
   - 任务时间变更或任务删除时，同步更新或删除对应日历事件。
3. **授权与降级**
   - 日历整合可选、尊重授权，未授权时明确提示并引导，而不是静默失败。
   - 平台不支持时优雅降级为应用内提醒。

## Acceptance Criteria

- [ ] 专注结束（进入「时间到」状态）时播放提示音，可在设置中关闭。
- [ ] 提醒触发时播放提示音，且可与专注音效独立关闭。
- [x] 设置中可选择音色（至少 3 种：轻柔 / 提醒 / 闹铃），点击即试听；音量跟随系统音量。
- [ ] iOS / Android 开启「写入系统日历」后，带具体时间的提醒会创建日历事件并设置日历提醒；关闭开关会清理已创建事件。
- [ ] 行动时间修改或行动删除后，对应日历事件同步更新 / 删除，无残留提醒。
- [ ] 未获得日历权限时，设置页给出明确说明与「去授权」引导；拒绝后不反复弹窗。
- [ ] 桌面端 / Web 不渲染不可用的日历开关，改为说明「当前平台不支持系统日历，仍可使用应用内提醒」。
- [ ] 单元测试覆盖：提示音偏好读写、日历同步的创建 / 更新 / 清理纯逻辑；`pnpm verify:web` 全绿。
- [ ] 浏览器实测截图存入 `.verify/issues-54-56/`。

## Notes

- OS 通知声音只能引用打包音频文件，音量受系统控制；应用内播放同样保持 unity gain，音量完全由系统音量控制。
- 日历事件映射只存本机（设备级偏好），不进入 PowerSync 同步 schema。
- 不新增后台常驻服务，沿用现有提醒投递 / 对账机制。
