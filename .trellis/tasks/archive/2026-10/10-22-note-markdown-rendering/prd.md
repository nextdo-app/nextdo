# 行动备注支持 Markdown 渲染

## Goal

行动备注在 Now 卡片与项目详情中按 Markdown 渲染（粗体、斜体、行内代码、链接、列表、引用、标题），编辑器保留原始文本并新增预览

## Requirements

1. **R1 解析** — 支持块级：`#`–`######` 标题（渲染封顶 3 级）、`-`/`*`/`+` 与 `1.` 列表、`>` 引用、``` 围栏代码、空行分段；行内：`**粗体**`、`*斜体*`、`~~删除线~~`、`` `代码` ``、`[文本](链接)`、反斜杠转义。
2. **R2 降级** — 子集之外的输入必须原样保留为字面文本，绝不吞字符、绝不抛错。不配对的 `**`、`[x](y`、孤立反引号都按字面显示。
3. **R3 两处展示** — Now 列表的行动卡片用「行内」形态：所有块压成一段、保留强调、去掉换行，从而 `numberOfLines={2}` 仍然有效；项目详情用「块级」形态完整排版。
4. **R4 编辑器** — 编辑弹层与项目详情内联表单的备注框继续编辑**原始 Markdown**；内容非空时提供「预览 / 编辑」切换，预览走与列表完全相同的解析器。
5. **R5 日历** — 系统日历事件描述是纯文本字段，写入前剥掉 Markdown 标记（链接只保留文字），避免 `**重要**` 原样出现在别的应用里。
6. **R6 空值** — 空白备注不渲染任何节点（不产生空白行）。

## Acceptance Criteria

- [x] 解析器单测覆盖每个块级与行内构造，以及降级用例（不配对标记、孤立反引号、`snake_case` 不被当作斜体）。
- [x] 渲染组件单测：块级/行内两种形态、链接仅在块级且传入回调时可点、空备注渲染 `null`。
- [x] 日历事件描述去标记有回归断言（`**带合同**，见 [文档](…)` → `带合同，见 文档`）。
- [x] `pnpm verify:web` 全绿（lint / typecheck / 全部包测试 / build:web）。
- [x] 浏览器实测截图见 `.verify/10-22-note-markdown-rendering/`。
- [ ] 真机确认：iOS/Android 上备注渲染与日历事件描述的实际观感（需设备，未在本轮验证）。

## 不做

- 不引入任何 Markdown 运行时依赖：`packages/core` 零依赖是硬约束，而备注是一两段自由文本，不是 README。
- 不实现表格、脚注、HTML 内嵌、图片、引用式链接、任务列表复选框。
- 不改备注的存储格式与同步路径：存的就是用户输入的原文。
