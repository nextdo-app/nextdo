# 解决 issues #58–#62（记录/澄清解耦、专注时长与通知、习惯打卡、项目可选首个行动）

## Goal

解决 #58 记录与澄清解耦（含批量澄清入口与专注页速记）、#59 专注时长自定义（常见档位+自定义输入+持久化）、#60 专注/休息结束的系统级通知与权限引导、#61 习惯打卡的高可见入口与单步打卡、#62 项目澄清不强制首个行动 + 行动类型（下一步/等待/委派）与等待清单。

## Requirements

### #59 专注时长应支持自定义
- 专注前可设置时长：常见档位（15/25/45/60 分钟）+ 自定义输入（1–180 分钟整数）。
- 选择结果持久化，下次进入专注前默认沿用上次的值。
- 未设置过时保持原默认行为（25/45/60 + 自由计时）。
- 当前没有休息时长功能，因此「如有休息时长也支持自定义」不适用（不新增休息计时器）。

### #58 流程优化：记录与澄清解耦
- 记录默认只落库（进入待澄清状态），不强制立即进入澄清；保留「记录并澄清」快捷路径。
- 收件箱即待澄清列表：明确的「待澄清」计数与「开始澄清」批量入口，done 步骤支持「澄清下一条」。
- 专注页提供轻量「速记」入口：记录不触发澄清、不导航、不中断当前专注计时。

## Acceptance Criteria

### #60 专注 / 休息结束的系统级通知
- [ ] 专注计时页在未授权时给出系统通知权限引导；拒绝或平台不支持时不阻塞计时。
- [ ] 专注到时即使 App 在后台/锁屏也会收到系统通知，并可在页内完成「行动也完成？」的收尾。
- [ ] 专注到时提供 5 / 10 分钟休息；休息计时同样调度系统通知，可提前结束。

### #61 习惯打卡的高可见入口
- [ ] Now 页顶部出现「今日习惯待打卡」卡片，展示未打卡习惯并可一键「快速打卡」。
- [ ] 打卡后该条从卡片消失；全部完成后卡片消失。
- [ ] 卡片最多展示 3 条，多余显示「还有 N 项…」并在「管理」中查看。

### #62 项目澄清不强制首个行动 + 行动类型
- [ ] 项目澄清可「先挂着」创建：不填首个行动标题也能保存，预览显示「首个行动：暂不设定」。
- [ ] 行动表单提供「行动类型」：下一步行动 / 等待外部 / 已委派。
- [ ] 等待类行动记录等待对象，进入等待清单（带类型标签），不进 Now 执行池；收到结果后可移出。

- [ ] 专注前可修改专注时长并生效；自定义 1–180 整数生效。
- [ ] 上次选择的时长持久保存，并在下次选时长时作为默认选项展示。
- [ ] 未修改时保持原默认（25/45/60 + 自由计时）。
- [ ] 记录任务时可跳过澄清，任务留在收件箱待澄清。
- [ ] 收件箱有明确的待澄清列表/计数与批量澄清入口（开始澄清 → 逐条处理）。
- [ ] 专注页底部常驻「速记一笔」坞，保存后停留在专注页并给出轻提示，计时不中断。
- [ ] `pnpm verify:web` 全绿，并完成浏览器实测截图（`.verify/issues-58-59/`）。
