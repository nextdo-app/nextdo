# PRD: 修复 issues #50 #51（习惯时间选择器与两分钟行动流转）

## 1. 目标与总揽
本父任务统筹解决 Nextdo 仓库当前未关闭的两个核心体验缺陷，并在交付前严格执行 Web 验证门禁、浏览器实测与 6 处版本号升级，最终发布测试版 `v0.1.8-beta.1` 并提交 PR。

## 2. 子任务拆分与交付物
1. **子任务 1：修复手机端习惯时间选择器高度坍缩（Issue #50）** (`10-18-habit-time-picker-mobile`)
   - 修复 `DateTimePicker` 在移动端 Yoga 引擎下因 `flex-1` 导致 ScrollView 坍缩为 0 的问题。
   - 确保小时/分钟转盘、时段选择、微调按钮在各种移动端视口（360px、390px、405px）及桌面端下完整可见可操作。
2. **子任务 2：修复两分钟行动完成与流转逻辑（Issue #51）** (`10-18-two-minute-action-flow`)
   - 落实「唤起 2 分钟专注」：选择「是，现在就做完」时，物化生成行动并立即进入 2 分钟专注倒计时。
   - 专注确认完成后，行动状态持久化为 `done`，正确出现在「已完成行动」列表中且支持恢复。
   - 专注未完成或退出时，行动保持 `open`，留在「现在」待完成执行池中，消除行动消失缺陷。

## 3. 集成与发版验收标准
- [ ] 子任务 1 与子任务 2 实施完成并通过自身测试。
- [ ] 浏览器多视口实测证据完备（`.verify/issues-50-51/` 截图与 `checks.json`）。
- [ ] 6 处版本号升级为测试版 `0.1.8-beta.1`。
- [ ] 全量质量门禁（lint + typecheck 5 个子工程 + test 100% + web build）全部绿灯通过。
- [ ] 按 trellis 规范提交代码、归档任务、记录 journal，最后推送到 GitHub 提交 PR。
