# 表单字段常显标签

## Goal

移动端各内联表单的字段名改为常显标签（FormField），placeholder 只作提示；覆盖项目/行动/习惯/等待/场景/设置高级字段，并补浏览器实测截图证据

## Requirements

- **R1 字段名常显**：每个表单字段的字段名以可见标签（`FormField`）渲染在控件上方，空态与已填写状态都显示；placeholder 只保留为框内提示。
- **R2 覆盖本次出现的全部表单**：项目详情页四个内联表单（添加行动 / 编辑项目 / 编辑行动 / 新建项目习惯）、项目 Tab 的新建项目表单、习惯创建表单与编辑习惯表单、等待事项表单、新场景表单、设置页「高级设置与手动输入」里的两个地址输入框。
- **R3 不改契约**：字段的 `accessibilityLabel`、placeholder 文案、提交/校验逻辑、可访问性角色全部保持不变（现有测试用 placeholder 与 label 定位字段）。
- **R4 不扩大范围**：收集箱的「清空大脑」捕获框、快速捕获弹窗输入框、Now 屏点开分钟芯片后的内联编辑、澄清向导（已有 `Field` 标签）不加标签。
- **R5 证据**：按 `.trellis/spec/project/quality-guidelines.md` 的 Web 验证门禁，在真实浏览器里把表单填上内容后截图，产物存 `.verify/form-field-labels/`。

## Acceptance Criteria

- [ ] AC-1 项目详情页「编辑项目」表单：标题、结果两个已填输入框上方分别显示「项目标题」「完成是什么样（结果）」，「截止日期」常显。
- [ ] AC-2 项目详情页「添加行动」「编辑行动」表单显示「行动标题」「截止日期」标签；「新建项目习惯」显示「习惯名」「每日行动」。
- [ ] AC-3 习惯创建表单与编辑习惯表单显示「习惯名」「每日行动」「预计分钟」；开启时间窗口后两个并排 picker 显示「开始时间」「结束时间」。
- [ ] AC-4 等待事项表单显示「事项名称」「等待谁」；新场景表单显示「场景名」；设置页高级设置显示「后端地址」「同步流地址」。
- [ ] AC-5 门禁：`pnpm lint`、`pnpm typecheck`、`pnpm test` 全绿；移动端 41 个套件 / 626 用例全通过。
- [ ] AC-6 浏览器实测：`.verify/form-field-labels/` 下的截图覆盖 AC-1 ~ AC-4 的每个表单（已填写状态），并在 `evidence.md` 里列出文件名与核验要点。
