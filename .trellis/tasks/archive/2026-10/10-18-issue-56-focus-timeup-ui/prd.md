# 优化专注页「时间到」提示卡视觉样式（#56）

## Goal

修复专注页「时间到」提示卡双层嵌套卡片、强调色块与按钮布局，使其成为单层、可读、操作清晰的提示卡。

## Requirements

Issue #56（截图见 issue 正文）指出，专注页计时结束后的「时间到」提示卡存在：

1. **双层嵌套卡片**：提示卡是 `Card`（默认 `elevated`，自带边框 + 底色 + 阴影），又嵌在外层白色大卡片里，加上 `border-warning` 与 `bg-warning/10`，形成「盒子套盒子」。
2. **边框过重**：`border-warning` 棕色边框存在感太强，边框粗细 / 圆角与其他组件不一致。
3. **按钮布局失衡**：「结束专注」「继续」两个按钮左对齐，右侧留白；次级按钮带阴影、主按钮扁平，风格不统一。
4. **标题缺乏层级**：「时间到」只是普通小号文字，没有视觉权重。
5. **计时器显示**：到 00:00 时仍是粗黑大字，状态转换生硬。
6. **间距节奏**：「下一步行动」标签行、大号计时数字、提示卡之间垂直间距不均匀。

## Acceptance Criteria

- [ ] 「时间到」区块是**单层容器**，不再出现 Card 嵌套 Card；warning 色仅用于小面积强调（图标 / 左侧色条 / 标题），不使用大面积边框 + 半透明底色叠加。
- [ ] 「时间到」有明确标题层级（加粗 / 更大字号，配提醒图标），与正文可区分。
- [ ] 两个操作按钮布局均衡（纵向全宽或居中排列），主 / 次级风格统一、圆角与阴影一致。
- [ ] 计时到 0 后数字视觉降级（变浅或显示实际用时），不再以粗黑大字呈现。
- [ ] 页面圆角统一 `rounded-2xl`，垂直间距落在 4 的倍数刻度上，三段内容（标签行 / 计时数字 / 提示区块）节奏均匀。
- [ ] 现有专注流程行为不变（开始 / 暂停 / 继续 / 结束 / 后续行动确认），`focus-screen` 相关测试全绿。
- [ ] 浏览器实测截图存入 `.verify/issues-54-56/`。
