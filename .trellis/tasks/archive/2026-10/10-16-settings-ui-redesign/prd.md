# 设置页面 UI 重构与视觉体验优化

## Goal

重构设置页面（Settings）的视觉层级与分组布局，统一开关与选择器交互控件，优化云同步与更新模块的信息排版，提升移动端与桌面端的整体设计质感。

## Requirements

### 1. 结构与分组层级（Section Grouping）
- 将原本平铺孤立的 6 个卡片重构为 4 个语义清晰的分组区域，每个区域配备简洁明了的小节标题（Section Header）：
  1. **通用与偏好**：外观主题（跟随系统 / 浅色 / 深色）+ 场景管理入口；
  2. **提醒与通知**：应用内通知总开关及系统权限状态 + 习惯打卡提醒开关与提醒时刻选择；
  3. **数据与同步**：云同步连接状态、配对/自建服务器配置、教程入口横幅、常见问题解答与断开连接；
  4. **关于与更新**：版本号与测试版标签、更新渠道选择、自动检查开关、手动检查更新按钮与更新日志。
- 将顶部副标题从狭隘的「设备与云同步。」更新为更准确全面的「个性化偏好、通知提醒与数据管理。」

### 2. 交互控件与一致性（Controls & Visual Details）
- **图标化与质感提升**：引入与 `Now` 页面同级的 `Ionicons` 图标体系。
  - 外观主题选项加入系统设备（`phone-portrait-outline`）、浅色（`sunny-outline`）、深色（`moon-outline`）图标；
  - 场景管理改造为标准的设置行 Cell（带场景图标与右向箭头 `chevron-forward`）；
  - 分组小标与状态加入对应色彩与图标点缀。
- **统一 Switch 开关**：
  - 移除应用更新卡片中手写的 `<Pressable>` 仿制 Switch，全页统一采用原生 `<Switch trackColor={SWITCH_TRACK_COLOR} />`，统一尺寸、滑块手感与无障碍支持。
- **云同步教程卡片化**：
  - 将原先突兀的纯文本/emoji 链接 `📖 查看 3 分钟零成本多端云同步教程...` 升级为精致的教程引导 Banner（带 `book-outline` 图标、柔和微色底、标签与箭头）。
- **云同步连接状态结构化**：
  - 已连接状态加入状态指示点（绿/黄/灰），后端地址与同步流地址做字段化分行排版，拒绝纯文本 Debug dump 感；
  - 「断开连接」操作在视觉上与普通同步/复制动作拉开层次，避免误触。

### 3. 响应式与桌面端排版优化（Responsive Layout）
- 将设置内容容器的最大宽度从 `max-w-5xl`（1024px，过宽空旷）收敛为人体工学舒适的 `max-w-2xl`（约 672px），并在宽屏下居中，使表单输入框和文字排版紧凑优雅；移动端保持全宽弹性自适应。

### 4. 兼容性与现有逻辑无损（Non-breaking Contracts）
- 保持所有现有的 React Hook 调用、事件监听、存储与状态契约不变。
- 现有的所有单测用例（`__tests__/settings-screen.test.tsx` 中全部 70 个测试）必须 100% 通过。
- 完美适配浅色模式（Light）与深色模式（Dark）。

## Acceptance Criteria

- [ ] 设置页面拆分为「通用与偏好」、「提醒与通知」、「数据与同步」、「关于与更新」四大分组且视觉节奏舒适；
- [ ] 外观主题选项具备图标与清晰的高亮反馈；
- [ ] 场景管理平滑内嵌为设置项 Cell，点击正常跳转至 `/contexts`；
- [ ] 全页 Switch 样式统一（消除 hand-rolled toggle）；
- [ ] 云同步模块未连接与已连接状态排版整洁，教程入口卡片化；
- [ ] 桌面端（大屏）与移动端（小屏）均呈现紧凑协调的视觉比例；
- [ ] `__tests__/settings-screen.test.tsx` 现有测试全部通过；
- [ ] `pnpm lint` 和 `pnpm typecheck` 零报错；
- [ ] 浏览器实测并生成截图记录在 `.verify/settings-ui-redesign/` 目录下。
